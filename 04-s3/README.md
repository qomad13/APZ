# Статичний сайт на AWS S3

Лабораторна робота №4 з АПЗ. Сторінка з ПІБ і групою. Її можна відкрити локально і викласти в бакет S3 як статичний сайт.

## Файли

- `index.html` - сторінка
- `style.css` - стилі
- `app.js` - кнопка на сторінці
- `s3-deploy.md` - як створити бакет і увімкнути хостинг
- `../звіти/Звіт_лабораторна_робота_4_Ледачков.docx` - звіт

## Локально

Відкрити `index.html` у браузері.

## На AWS

Ім'я бакета унікальне, латиницею, наприклад `ledachkov-illia-bucket-apz`, регіон `eu-north-1`.

1. Зняти блокування всього публічного доступу.
2. Завантажити `index.html`.
3. Дати об'єкту публічне читання.
4. У властивостях увімкнути статичний хостинг сайту і вказати індексний документ `index.html`.
