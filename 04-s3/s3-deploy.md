# Розміщення статичного сайту на AWS S3

## Мета
Закріпити навички створення сервісу хмарного зберігання AWS S3 та розміщення власної статичної веб-сторінки на AWS S3.

## Крок 1 - Створити обліковий запис AWS
- Зареєструватися на aws.amazon.com
- Обрати безкоштовний тарифний план (AWS Free Tier)

## Крок 2 - Створити файл статичної веб-сторінки
У текстовому редакторі створити файл `index.html` (уже надано у цьому проєкті):

```html
<!DOCTYPE html>
<html lang="uk">
<head>
  <meta charset="UTF-8">
  <title>Моя сторінка</title>
</head>
<body>
  <h1>Ледачков Ілля Сергійович</h1>
  <p>група 121-23-1</p>
</body>
</html>
```

## Крок 3 - Створити S3 бакет
- У консолі AWS перейти до сервісу **S3**
- Натиснути «Створити бакет»
- Ім’я бакету має бути унікальним і містити прізвище та ім’я латиницею (наприклад `ledachkov-illia-bucket-apz`)
- Обрати регіон (наприклад `eu-north-1`)

## Крок 4 - Відкрити публічний доступ
- Зняти прапорець «Блокувати весь публічний доступ»
- Підтвердити зміни

## Крок 5 - Завантажити файли та налаштувати доступ
- Завантажити `index.html` у створений бакет
- Для об'єкта `index.html` надати публічні права на читання (зробити публічним або через політику бакета)

## Крок 6 - Налаштувати статичний хостинг сайту
- У вкладці «Властивості» увімкнути статичний хостинг сайту
- У полі індексного документа вказати `index.html`
- Отримати публічну URL-адресу для доступу до сторінки

## Результат
Публічна статична веб-сторінка доступна за посиланням типу:
`https://<bucket-name>.s3-website-<region>.amazonaws.com`

## Примітки
- Ніколи не комітьте реальні ключі доступу AWS (`AWS_ACCESS_KEY_ID`, `AWS_SECRET_ACCESS_KEY`) до Git.
- У цьому проєкті надано лише файли сторінки та інструкцію; реальне розгортання виконується через консоль AWS або AWS CLI.
