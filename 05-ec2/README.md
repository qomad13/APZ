# Windows-машина в AWS EC2

Лабораторна робота №5 з АПЗ. Запуск Windows Server в EC2 і підключення до робочого столу по RDP.

## Файли

- `rdp-connect.md` - порядок запуску і підключення
- `create-student-doc.ps1` - створює на робочому столі ВМ текстовий файл з ПІБ і групою
- `user-data.ps1` - те саме, якщо вставити скрипт під час запуску інстансу
- `security-group.json` - приклад групи безпеки: порт 3389 тільки зі своєї IP
- `../звіти/Звіт_лабораторна_робота_5_Ледачков.docx` - звіт

## Як користуватись

1. Запустити інстанс Microsoft Windows Server (Free Tier) і скачати пару ключів `.pem`.
2. У списку інстансів відкрити **Actions - Security - Get Windows password** і розшифрувати пароль Administrator.
3. На своєму ПК відкрити `mstsc` і підключитись за публічною IPv4.
4. На ВМ запустити `create-student-doc.ps1`.

Файл `.pem` і пароль у репозиторій не класти.
