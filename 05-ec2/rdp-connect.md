# Підключення до Windows EC2 по RDP

## Мета
Розгорнути віртуальну машину (Instance) під управлінням ОС Windows у хмарному сервісі Amazon EC2 та підключитися до неї через RDP.

## Крок 1 - Запуск інстансу (Launch Instance)
1. У консолі AWS перейти до сервісу **EC2**.
2. Натиснути **Launch instance** (майстер створення екземпляра).
3. Обрати операційну систему **Microsoft Windows Server** (з підтримкою Free Tier).
4. Налаштувати тип інстансу (наприклад `t2.micro` - у межах Free Tier).
5. Створити та **завантажити на локальний ПК файл пари ключів (.pem)** для автентифікації.
6. Налаштувати групу безпеки (security group) - дозволити вхідний трафік RDP (порт 3389) лише з вашої IP-адреси.
7. Запустити інстанс.

## Крок 2 - Отримання облікових даних
1. У розділі **Instances** обрати створену віртуальну машину.
2. Меню: **Actions → Security → Get Windows password**.
3. Завантажити приватний ключ `.pem` та виконати розшифрування початкового пароля адміністратора (**Decrypt Password**).

## Крок 3 - Підключення до віртуальної машини
1. На локальному ПК запустити клієнт віддаленого робочого столу (**RDP / mstsc**).
2. Ввести зовнішню IPv4-адресу (Public IPv4) віртуальної машини.
3. Авторизуватися під користувачем **Administrator** із розшифрованим паролем.

## Крок 4 - Індивідуальне завдання
Після підключення до робочого столу ВМ створити графічний/текстовий документ із зазначенням ПІБ та групи студента.
Можна використати скрипт `create-student-doc.ps1` або `user-data.ps1` (виконується автоматично при запуску).

## Дані для підключення
- IP-адреса (Public IP): публічна IPv4 інстансу після запуску
- Логін (Username): `Administrator`
- Пароль (Password): розшифровується через .pem ключ

> ⚠️ Ніколи не комітьте реальні `.pem` ключі, паролі або облікові дані AWS до Git. У проєкті надано лише приклади/шаблони з замісниками.
