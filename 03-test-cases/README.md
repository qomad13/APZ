# Тест-кейси PulseWatch X1

Лабораторна робота №3 з АПЗ. Набір тест-кейсів для смарт-годинника PulseWatch X1: дисплей, бічна кнопка, датчик пульсу, зарядка і ремінець.

## Файли

- `test_cases.md` - кейси текстом
- `test_cases.json` - ті самі кейси у JSON
- `validate_tests.py` - перевіряє, що в кожному кейсі заповнені потрібні поля
- `../звіти/Звіт_лабораторна_робота_3_Ледачков.docx` - звіт

## Запуск

```bash
python validate_tests.py
```

Якщо поля на місці, скрипт пише `ПЕРЕВІРКУ ПРОЙДЕНО`.

## Компоненти

1. Сенсорний AMOLED-дисплей
2. Бічна кнопка / цифрова коронка
3. Оптичний датчик PPG (пульс і кисень у крові)
4. Акумулятор і магнітна зарядка
5. Силіконовий ремінець зі швидкознімним кріпленням
